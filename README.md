## תיאור הפרויקט

FashionSync היא חנות בגדים אונליין (ללא חנות פיזית) המאפשרת ללקוחות לגלוש בקטלוג, לקבל המלצות והתאמות לוק מצ'אטבוט חכם, לבצע הזמנות עם משלוח או איסוף עצמי, לצבור נקודות נאמנות ולהשתמש בקופונים וכרטיסי מתנה. לצד זה, קיים ממשק ניהול מקיף המאפשר למנהלת החנות לנהל מלאי, הזמנות, משלוחים, קבלות, החזרות, משוב לקוחות והגדרות המערכת — הכול מעודכן בזמן אמת מול Firebase.

## טכנולוגיות

**Frontend:**
- React 19 + Vite
- SCSS Modules
- Firebase SDK (Auth, Firestore, Storage)

**Backend:**
- Firebase Cloud Functions (Node.js 22)
- Google Gemini AI (צ'אטבוט חכם + הדמיית לוקים)
- Gmail API (שליחת מיילים אוטומטיים)
- Secret Manager (אבטחת מפתחות API)

**מסד נתונים:** Cloud Firestore (בזמן אמת, ללא צורך ברענון ידני)

## תכונות עיקריות

### צד לקוחות
- קטלוג מוצרים עם סינון וחיפוש, תמיכה בשתי שפות (עברית/אנגלית) ובמצב כהה/בהיר
- צ'אטבוט חכם ("SYNC") שעונה על שאלות לפי נתונים חיים מההגדרות (מדיניות, שעות פעילות, כתובת), ומציע התאמות לוק אישיות
- עגלת קניות, Checkout, מעקב הזמנות ומשלוחים
- תוכנית נאמנות, קופונים וכרטיסי מתנה
- בקשות החזרה וביטול הזמנה עצמאיות

### צד ניהול
- ניהול מלאי מוצרים (כולל וריאנטים לפי צבע/מידה)
- מעקב הזמנות, משלוחים וקבלות מכירה
- טיפול בבקשות החזרה, הודעות יצירת קשר ומשוב לקוחות
- ניהול קופונים, הגדרות מדיניות, שעות פעילות ופרטי חנות
- דוחות ואנליטיקה מבוססי נתונים חיים

## מבנה הפרויקט

fashion-sync-react/
├── frontend/ # אפליקציית React (צד לקוחות + צד ניהול)
│ └── src/
│ ├── components/ # רכיבי ממשק
│ ├── pages/ # דפי האתר
│ ├── services/ # שכבת תקשורת עם Firestore
│ ├── functions/ # לוגיקה עסקית לפי אזור (לקוחה/מנהלת/checkout)
│ ├── translations/# תרגומים (עברית/אנגלית)
│ └── styles/ # עיצוב (SCSS Modules)
└── backend/ # Cloud Functions
└── src/
├── controllers/ # נקודות כניסה ל-API
└── services/ # לוגיקת שרת (AI, מיילים, וכו')


## התקנה והרצה מקומית

```bash
# פרונט
cd frontend
npm install
npm run dev

# בק־אנד (במידת הצורך)
cd backend
npm install --break-system-packages
```

## פריסה (Deployment)

```bash
cd backend
npx firebase-tools deploy --only functions:<שם הפונקציה>
```
